# mubnyevents

Website for MUBNY Events & Banquets — a 5,000 sq. ft. banquet hall in Buffalo, NY seating 300+ guests.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The whole site. Single self-contained file. |
| `photos/` | Venue photography used by the gallery and hero. |
| `mubny-logo.png` | Logo — favicon, header, footer. |

Open `index.html` in a browser to view it locally. No build step, no dependencies.

## Deploying

GitHub Pages: Settings → Pages → Source: `main` branch, `/ (root)`.

Netlify or Cloudflare Pages: connect the repo, leave the build command empty, set the publish directory to `/`.
